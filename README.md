## 🧠 Overview

- **Certification:** AWS Certified Cloud Practitioner (CLF-C02)  
- **Level:** Foundational  
- **Exam Duration:** 90 minutes  
- **Questions:** ~65  
- **Passing Score:** 700 / 1000  
- **Format:** Multiple Choice & Multiple Response

## ⚡ Last-Minute Recall Sheet

- ☁️ **6 Pillars of AWS Well-Architected Framework**
  - Operational Excellence
  - Security
  - Reliability
  - Performance Efficiency
  - Cost Optimization
  - Sustainability  

- 🔐 **Shared Responsibility Model**
  - AWS: *Security of the Cloud* (hardware, infra)
  - You: *Security in the Cloud* (data, IAM, OS)

- 💰 **Cost Tools**
  - AWS Pricing Calculator  
  - AWS Budgets  
  - AWS Cost Explorer

## 💡 My Personal Tips

✅ Understand **core AWS services** (EC2, S3, Lambda, RDS)  
✅ Learn **security basics** (IAM, KMS, Encryption, Compliance)  
✅ Use **AWS Skill Builder** & **free practice exams**  
✅ Focus on **cost optimization** & **support plans**  
✅ Don’t memorize — understand the *why* behind AWS features
